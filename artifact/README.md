# Reproducibility artifact

This directory is the release-facing layer for the quantitative examples in
the paper. It contains only material that can be redistributed or fetched from
a public, versioned source. Companion-project matrices are not copied here and
must not support load-bearing claims.

## Rebuild the public core

From the repository root, run:

```powershell
powershell -ExecutionPolicy Bypass -File artifact\build_public_core.ps1
```

The command verifies the Python environment, records SHA-256 checksums of local public inputs, runs the core analyses, and writes a timestamped manifest under `artifact\builds\`. It does not download or overwrite data.

## Provenance

| Source | Retrieval route | Artifact status |
|---|---|---|
| MoralChoice responses | `external_sources/moralchoice` at recorded Git commit | public source; frozen analysis copy |
| PromptEval MMLU correctness | `PromptEval/PromptEval_MMLU_correctness` on Hugging Face | public MIT-licensed source; frozen analysis copy |
| MT-Bench pair judgments | `external_sources/FastChat` at recorded Git commit | public source; frozen analysis copy |

Run `artifact\fetch_public_sources.ps1` on a clean checkout. It checks out the
pinned MoralChoice release, copies the 24 response matrices used here, downloads
the selected PromptEval matrices, and retrieves the released MT-Bench pair
judgments with a SHA-256 check. Before archival upload, record the resolved
source commits and checksums generated by `make_manifest.py`.
Pinned revisions and source licenses are listed in
`THIRD_PARTY_ASSETS.md`. The public core consists of deterministic CPU
re-analyses of released model outputs and requires no model training, model
inference, or GPU.

## Scope

The public core supports claim-relative strict-$\phi$ examples and broad $\phi$
for MoralChoice, whose five repeats separate interaction from run noise.
PromptEval and MT-Bench do not identify broad $\phi$ because those releases have
one observation per item-by-probe cell. The prepared repeated-judge extension
must be run before any broad-$\phi$ claim for open-ended judging.

The final 30-cell coverage map and representative evidence are released in
`coverage_coding.csv`. Raw independent coder outputs were not retained, so the
reported agreement statistic is not reconstructable and the map is exploratory.
Update and correction rules are in `GOVERNANCE.md`.

Original project code and documentation use the root MIT license. Third-party
corpora remain fetched from their licensed upstream releases rather than
repackaged.
